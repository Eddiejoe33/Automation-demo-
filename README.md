## 🔧 Features
- Web scraping to extract structured data
- Data processing and export to **CSV** and **JSON**
- Automation scripts for scheduled email reports and posting results
- Portable environment setup for mobile and desktop use

---

## 🧰 Tech Stack
- **Language:** Python  
- **Storage:** CSV, JSON  
- **Automation:** cron / scheduled scripts  
- **Dev tools:** Git & GitHub, virtual environments  
- **Platforms:** Linux, Android (UserLAnd)

```bash
git clone https://github.com/Eddiejoe33/Automation-demo-.git
cd automation-demo
python3 -m venv env
source env/bin/activate
pip install -r requirements.txt
python scraper/main.py
